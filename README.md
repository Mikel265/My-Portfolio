# 💻 Running the Project Locally

## 1. Clone the repository

```bash
git clone https://github.com/Mikel265/mikel-portfolio.git
cd mikel-portfolio
```

## 2. Start a local development server

### Using Python

```bash
python -m http.server 8080
```

### Or using Node.js

```bash
npx serve .
```

## 3. Open the website

Visit:

```text
http://localhost:8080
```

# 🌐 Deployment

The portfolio is hosted on **Netlify**.

### Deploy using GitHub

```bash
git init
git add .
git commit -m "Deploy Mikel Graphicals Portfolio"

git branch -M main

git remote add origin https://github.com/Mikel265/mikel-portfolio.git

git push -u origin main
```

Then connect the GitHub repository to your Netlify account and deploy the project.
